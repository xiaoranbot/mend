mend is a command-line tool that applies AI-written edits in four formats — unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON tool calls — to a tree of text files, matching lines even when the model drifted their whitespace or indentation, and changing every file or none.

## Run it

```sh
node main.ts patch.diff
```
